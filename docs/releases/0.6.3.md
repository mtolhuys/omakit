# 0.6.3

The command and documentation table is back directly below the README's
introduction and status badges. It lists every current command, gives each a
short plain-language purpose, and links straight to its documentation.

The Socket image badge is gone. Its badge endpoint returns a Cloudflare 403
HTML challenge instead of an SVG to automated consumers, which made npm show
a broken image. This is a presentation-only release; Omakit's command
behaviour is unchanged.

Upgrade with:

```bash
omakit upgrade
```
