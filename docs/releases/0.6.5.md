# 0.6.5

Tested plumbing, the marketplace's own checks, and a disposable Omarchy to test in.

The marketplace pin moves from `38060f89` (2026-09-11) to `70dcc454`
(2026-09-21, "Add LookAway plugin (#7750)"). Since 2026-09-20 `omakit
doctor` reported `pin.freshness` as a note: two of the 863 marketplace
commits since the old pin touched `scripts/` or
`.github/ISSUE_TEMPLATE/`, the paths omakit reads code and rules from and
never fetches live.

## What moved at the marketplace

- 7dd6e56 ("Fix catalog search and add VPN and Bar filters (#7756)") adds
  the tag `vpn` to `allowedTags` in `scripts/submission.mjs` and to the
  Tags list in `submit-plugin.yml`. Both are read from the pin, so
  `omakit submit --tags vpn` is accepted without a code change, and the
  usage error for a missing `--tags` now lists fourteen tags.
- 40315f2 ("Reuse installer-only reviews for standard installation
  (#7755)") lets a standard-installation verification reuse a valid
  installer-only maintainer review (`scripts/plugin-verification.mjs`, a
  new `securityBaselineEligibleForReviewedStandardInstallation` in the
  policy module, wording in `verify-plugin.yml`). That is the maintainer's
  flow after listing; nothing the preflight, `watch` or `audit` reads.

`securityBaselineVersion` is still `3`, enforcement still `selective`, and
the rule and capability catalogs, the limits, the 37-code feedback table
and the label set are byte-identical at both commits. No verdict changes.

## What follows in omakit

The registry figures the tool prints and the docs cite are the new pin's,
recomputed by `tests/unit/registry-figures.test.mjs`: 3,653 listed sources,
3,608 with a recorded baseline (2,025 passed, 1,557 review-required, 26
needs-fixes), 3,691 catalog ids, 22 retired; 854 sources (23.4%) with a
superseded validated commit, 1,270 superseded commits. Parity of the local
baseline run against the marketplace's own recorded outcomes is re-proved
over the 30-repository corpus at the new pin:
`docs/evidence/parity/2026-09-21-local-vs-github.json`.
`docs/UPSTREAM_CONTRACT.md` carries the new pin, the figures and a pin
history. The `inspect` fixtures name the new pin.

The pinned checkout is 22 MB sparse at this commit. `omakit pin` re-fetches
it on first use after the upgrade; `omakit doctor` then reports
`pin.freshness` as `ok`.

Upgrade with:

```bash
omakit upgrade
```
