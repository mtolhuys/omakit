# 0.6.1

Tested plumbing, the marketplace's own checks, and a disposable Omarchy to test in.

This is the first published release in the 0.6 line. The `v0.6.0` workflow
stopped before publishing an npm package or GitHub Release, so its tag remains
at the commit it named and this recovery uses the next unused version.

The recovery removes two sources of release-only failure. Lab host-command
checks now honor the environment supplied by their caller, so CI can prove the
missing-command paths without depending on what happens to be installed on a
runner. CI also records the source commit and runs the suite from the resulting
Git-free archive before it accepts the package: the same archive shape the
release publishes, including the commit record used by `omakit add`.

The 0.6 line adds:

- the Run 0.2.1 and Store 0.2.0 blocks, installed with `omakit add` and
  recognized by `inspect`;
- `omakit lab setup`, `inspect`, `prove` and `prune`, with the Run, Store and
  weigh suites running in a disposable Omarchy guest;
- the 2026-09-19 acceptance hardening for command outcomes, argument handling,
  pin races, symlink inspection, release commit identity and `weigh` restore
  behavior.

The full contracts, measurements, guest records and limits are in the
[0.6 release record](0.6.0.md). Nothing here says a plugin passes review, and
no reviewer has seen a ported plugin yet.

Upgrade with:

```bash
omakit upgrade
```

or install this version directly:

```bash
npm install --global omakit@0.6.1
```
