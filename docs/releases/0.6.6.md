# 0.6.6

Tested plumbing, the marketplace's own checks, and a disposable Omarchy to test in.

The marketplace pin moves from `70dcc454` (2026-09-21 05:35 UTC) to
`b7b29654` (2026-09-21 18:18 UTC, "Add OmaStudio plugin (#6843)"), the
same day as 0.6.5. `omakit doctor` reported `pin.freshness` as a note that
evening: of the 14 marketplace commits since 0.6.5's pin, one touched
`scripts/`, a path omakit reads only from the pin.

## What moved at the marketplace

5e401552 ("Delist multi-monitor.workspaces and preserve retired migration
history (#7954)") lets `validateRegistryRepositoryMigrations` in
`scripts/repository-identity.mjs` accept a repository-migration chain that
ends at fully retired plugins instead of an active source, and delists
`multi-monitor.workspaces`. Omakit does not import that module: it is the
marketplace's validation of its own registry, on their side. The security
baseline version (3), the enforcement mode (`selective`), the rule and
capability catalogs, the limits, the 37-code feedback table, the label set
and the submission form are byte-identical at both commits. No verdict
changes.

## What follows in omakit

The registry figures the tool prints and the docs cite are the new pin's,
recomputed by `tests/unit/registry-figures.test.mjs`: 3,664 listed sources,
3,619 with a recorded baseline (2,031 passed, 1,562 review-required, 26
needs-fixes), 3,702 catalog ids, 23 retired (one more: the delisting above);
854 sources (23.3%) with a superseded validated commit, 1,270 superseded
commits. Parity of the local baseline run against the marketplace's own
recorded outcomes is re-proved over the 30-repository corpus at the new pin;
the evidence file for this date is in `docs/evidence/parity/` and named in
`docs/UPSTREAM_CONTRACT.md`, which also carries the pin history. The
`inspect` fixtures name the new pin.

Since 0.6.5, on `main`: the weekly pin-freshness workflow reads `doctor`'s
verdict as `doctor` gives it (`ok` with unequal commits when only the
live-read data files moved, `advice` naming the pinned paths that did); it
had failed on every scheduled run since 2026-09-14. A fresh `omakit pin`
measures 19 MB, not the 22 MB the 0.6.5 notes said.

`omakit pin` re-fetches the checkout on first use after the upgrade;
`omakit doctor` then reports `pin.freshness` as `ok`.

Upgrade with:

```bash
omakit upgrade
```
