Terminal output now adapts to the available width instead of leaving help and reports fixed at eighty columns.

- Interactive help reflows descriptions and command signatures to the terminal's current width, up to 120 columns for readable prose. Narrow windows wrap earlier; wide windows use the extra space.
- Reports, section rules and confirmation questions use the same responsive geometry. Check headers move their source to another line when it cannot fit beside the check name.
- A terminal narrower than the logo gets a compact wordmark, avoiding cursor animation across wrapped artwork.
- Pipes retain the stable eighty-column layout. Text files written with `--out` use that layout without terminal colour escapes. JSON and exact marketplace reports, issue bodies, URLs and commit identifiers remain intact.

Validation includes real pseudo-terminal help at narrow and wide sizes, text-preservation and colour checks at six widths, and visual inspection of captured output using the current JetBrains Mono font and terminal palette. No dependencies or CLI commands were added.
